# Security policy

## Supported version

The deployed site and the current `main` branch are supported. Historical
commits, local forks, and unpublished drafts are not maintained releases.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form:

<https://github.com/AdriRRP/quihacker.site/security/advisories/new>

Include the affected URL or file, reproduction steps, impact, and any suggested
mitigation. Do not publish exploit details, credentials, private device data, or
proofs of concept in a public issue.

Reports should receive an initial acknowledgement within seven days. Remediation
and disclosure timing depend on severity, exploitability, and coordination with
affected third parties.

## Scope

Relevant reports include deployment-workflow compromise, cross-site scripting,
dependency or CDN compromise, domain or Pages misconfiguration, leaked secrets,
and unsafe publication of research artifacts. General content corrections and
broken links can use a normal GitHub issue.
